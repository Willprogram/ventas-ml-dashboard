# 🤖 Plataforma Inteligente de Análisis y Predicción de Ventas

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](ventas-ml-dashboard-j4kkvfuzyiukaoxheyy7as-willprogram.streamlit.app)

## 📌 Descripción del Proyecto
Esta aplicación es una solución integral de **Business Intelligence** y **Machine Learning** diseñada para directores comerciales y analistas de datos. Permite transformar registros históricos de ventas en una herramienta interactiva para la toma de decisiones estratégicas.

A diferencia de los reportes estáticos en Excel, este sistema utiliza un modelo de **Random Forest** para simular escenarios y predecir el comportamiento del mercado con base en estacionalidad y tácticas de marketing.

---

## 🚀 Funcionalidades Clave

### 📊 1. Dashboard Histórico Dinámico
* **Visualización Inteligente:** Gráficos interactivos con escala logarítmica para identificar tendencias en diferentes órdenes de magnitud.
* **KPIs de Rendimiento:** Tarjetas de métricas con cálculo automático de crecimiento comparativo (Mes actual vs. Mes anterior).
* **Segmentación Temporal:** Filtro de fechas avanzado para análisis de periodos específicos.

### 🔮 2. Predicción a Corto Plazo (Forecasting)
* **Proyección Semanal:** El sistema genera una estimación de ventas para los próximos 7 días a partir de cualquier fecha seleccionada por el usuario.

### 🎛️ 3. Simulador de Estrategia Comercial
* **Análisis "What-if":** Permite al usuario configurar variables (Mes, Día, Festivos, Promociones) para obtener una predicción inmediata de ventas. Ideal para planificar presupuestos de marketing.

### 🚨 4. Detección de Anomalías
* **Auditoría de Datos:** Identifica automáticamente días donde las ventas reales se desviaron significativamente del comportamiento esperado, facilitando la detección de errores de registro o picos inusuales de demanda.
